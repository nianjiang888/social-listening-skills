# 中文舆情监听 · 六端数据源与评分卡

本文件是 cn-social-listening 的配套参考。所有检索都走"网页搜索 + 网页读取"能力，不依赖任何平台登录态。下面给的是每端的**查询构造模板**和**抓取要点**，以及统一的评分卡。

---

## 一、六端查询模板

每个对象，逐端至少跑 3 组查询：`<对象> + 口碑词` / `<对象> + 负面词` / `<对象> + 时间词`。下面是每端的高频组合，按对象名替换占位符 `{O}`。

### 小红书（种草 / 测评 / 翻车集中地）
- `{O} 小红书 测评`
- `{O} 小红书 踩坑`
- `{O} 真实使用 吐槽`
- 抓取要点：笔记标题即态度，重点看"测评/踩坑/避雷/平替"类；互动看点赞+收藏（小红书收藏权重高）。

### 抖音（声量最大、情绪最外放）
- `{O} 抖音`
- `{O} 翻车 抖音`
- `{O} 吐槽 抖音`
- 抓取要点：口播类内容看评论区热评，热评往往比视频本身更说明风向；留意"挑战/合拍"类二次传播。

### 知乎（理性长评、专业向）
- `{O} 知乎 怎么看`
- `{O} 知乎 评价`
- `{O} 知乎 值得买吗`
- 抓取要点：高赞回答的"结论句"和"反对派高赞评论"都要抓，知乎的价值在分歧本身。

### 微博（热点发酵、危机第一现场）
- `{O} 微博 热搜`
- `{O} 微博 吐槽`
- `{O} 超话`
- 抓取要点：看话题阅读量、热搜排序、大 V 转发；负面危机几乎都在微博先爆。

### B站（深度测评、年轻人向）
- `{O} bilibili 测评`
- `{O} B站 吐槽`
- `{O} UP主 评价`
- 抓取要点：长视频看弹幕峰值和评论区高赞；B站用户容错低，专业向吐槽伤害大。

### 今日头条（下沉市场、年龄偏大用户）
- `{O} 今日头条`
- `{O} 头条 新闻`
- `{O} 事件 最新`
- 抓取要点：看评论区下沉市场真实反馈，常补足其他五端覆盖不到的群体。

### 补充通用源（扩面用）
- 百度：`{O} 最近 新闻`、`{O} 百度指数`（看趋势）
- 微信：`{O} 微信 文章`（看公众号深度稿，网页搜索可命中）

## 二、评分卡（三因子，每条内容独立打分）

| 因子 | 取值 | 说明 |
|---|---|---|
| 参与度 | 高 / 中 / 低 | 用**端内相对值**，不跨端比绝对数。微博 10 万赞算高，小红书 1 万赞算高，量级不同。取互动量（赞+评+转+藏）在端内的相对位置。 |
| 相关性 | 强 / 弱 | 强=明确在说这个对象本身；弱=蹭热度/只提名字/泛指行业。弱的不计入簇声量，仅作背景。 |
| 新鲜度 | 近 7 天 / 近 30 天 / 超窗 | 默认时间窗近 30 天；近 7 天权重最高，危机类尤其看近 7 天。 |

**簇声量** = 簇内所有"强相关"内容的参与度汇总（跨端相加，但标注各端占比）。排序用簇声量，不用单条。

**情绪判定**：对每条强相关内容标 正向 / 中性 / 负面，簇的情绪取主要倾向；明显分化的簇标"分化"并分别给两侧代表内容。

## 三、诚实备忘（写进简报的底线）

- 某端搜不到有效样本，简报里写"该端样本不足"，不编。
- 互动量是抓取时刻的快照，不是实时统计，简报里注明"基于抽样样本"。
- 平台反爬可能导致某些端样本偏少，属正常，标充足度即可，不要为了凑数去猜。
- 涉及危机定级、法律风险判断，必须提示"建议人工复核"，本技能不替代人工决策。
