# 中文舆情监听助手 (cn-social-listening)

当用户说「舆情 / 口碑 / 品牌声量 / 用户怎么看 / 有没有翻车 / 某个牌子最近风评 / 帮我盯一下这个话题 / 出份舆情简报」时触发。

## 它是什么（人格锚：无，纯研究域）

cn-social-listening 不是爬虫，也不是搜索聚合器。它是一个**舆情研究工作流**：你给它一个对象（品牌、产品、人物、事件、话题），它按一套固定打法在六个中文平台把近 30 天的真实讨论捞出来，打分、聚类，最后合成一份人能直接拿去汇报的简报。

和"搜一下返回十条链接"的区别在于：它要的是**结论**，不是链接堆。它必须告诉你这事现在口碑是往上还是往下、谁在带节奏、哪句话最扎心、风险点在哪。

这套打法的核心思路借自海外的 last30days 类舆情研究技能（预解析账号与话题、多源并行、按真实参与度排序、跨平台合并同一事件），但数据源和输出全部重写为中文社媒场景，没搬任何原文。

## 能做什么

- 围绕一个对象，出一份近 30 天的中文社媒舆情简报。
- 覆盖六端：小红书、抖音、知乎、微博、B站、今日头条。
- 每一条关键结论都带出处（平台 + 可定位的帖子/话题），不空口说"网友普遍认为"。
- 按真实声量（互动量、转发、评论热度的综合）排重要性，而不是按 SEO 排序。
- 跨平台合并：同一件事在微博爆了、抖音跟了、小红书出测评，归到一个簇里讲。

## 边界（先说清楚，免得指望错）

- 它依赖当前环境里可用的**网页搜索 / 网页读取工具**。平台登录墙后的内容（私信、部分仅粉丝可见）拿不到，这是正常的，不是缺陷。
- 不保证全量。声量是"抽到的有效样本"的相对排序，不是精确实时统计。涉及重大决策（如危机公关定级）必须再人工核一遍。
- 不替你下"必须删帖/必须回应"的指令。它给判断依据，动作你自己定。
- 不伪造数据。抽不到就写"该端样本不足"，不编互动量。

## 核心工作流（六步，严格按顺序）

**第 0 步：预解析（最关键，别跳过）**
动手搜之前，先把对象拆开：相关账号（官号、创始人、关键 KOL）、子话题（产品名/型号/梗/负面关键词）、同义叫法。比如对象是"某奶茶品牌"，要预列出：品牌官号、创始人、近期新品名、常见吐槽词（"难喝""排队""拉肚子"）。这一步决定后面搜得准不准。

**第 1 步：收对象**
从用户那拿到：对象名 + 时间窗（默认近 30 天）+ 关注点（口碑 / 危机 / 竞品对比 / 新品反馈）。关注点没说就默认"整体口碑"。

**第 2 步：六端并行检索**
按 references/sources.md 里的每端查询模板，逐端跑网页搜索，每端至少 3 组不同角度的查询（对象名 + 口碑词 / 对象名 + 负面词 / 对象名 + 时间词）。各端独立，能并行就并行。

**第 3 步：评分**
对每条抓到的内容，按三因子打分（细则见 references/sources.md 的评分卡）：
- 参与度：互动量越高越靠前（不同端量纲不同，用端内相对值）。
- 相关性：是不是真在说这个对象，不是蹭热度的泛讨论。
- 新鲜度：时间窗内越近权重越高。

**第 4 步：跨平台聚类**
把指向同一事件/同一说法的内容合并成一个簇。例如"微博吐槽包装丑"和"小红书发图说包装丑"和"抖音口播说包装丑"是同一簇，合成一处，跨端声量相加。

**第 5 步：合成简报**
按下面的结构输出。结论先行，每条带引用，按簇声量从高到低排。去 AI 味：别写"综上所述""值得注意的是"，直接说事。

**第 6 步：标注与兜底**
写明各端样本充足度；样本不足的端单独标"样本不足，结论参考"。给一句"建议下一步"（如人工复核某条高声量负面、或扩大时间窗复看）。

## 输出简报结构（固定，别自由发挥）

```
# 《对象》近 30 天中文社媒舆情简报
生成时间：YYYY-MM-DD  时间窗：近 30 天  覆盖：小红书/抖音/知乎/微博/B站/头条

## 一句话结论
（口碑整体向上/向下/分化，最大变量是什么，用一句大白话）

## 声量总览
- 各端有效样本数：小红书 N / 抖音 N / 知乎 N / 微博 N / B站 N / 头条 N
- 整体情绪分布（基于样本）：正向 ~% / 中性 ~% / 负面 ~%

## 关键簇（按声量从高到低）
### 簇 1：<一句话事件>
- 声量：跨端合计约 N（微博为主 / 小红书为主…）
- 立场：正向/负面/分化
- 代表内容：<平台> <可定位描述或链接> —— 一句话原意
- 为什么重要：<对品牌/对象意味着什么>

### 簇 2：…
（以此类推）

## 风险点与机会点
- 风险：<最该盯的一条，带出处>
- 机会：<最值得放大的正向声量，带出处>

## 样本说明与下一步
- 各端样本充足度：…
- 建议：…
```

## 怎么算"做好了"

一份合格的简报，用户不用再打开任何链接就能向老板/客户讲清楚"这事现在什么风向、谁在说、该不该管"。如果简报里全是"网友认为"却没有一处可定位的出处，就是不及格，回去补第 2、3 步。
